# GroupBuffToggle — architecture

**Author:** Babuni.dev

GroupBuffToggle.lua creates Blizzard-style checkboxes and adjacent buff displays, showing up to sixteen auras per unit; settings persist in its saved variables. Upgrade-SavedData.ps1 handles renamed addon data.

Evidence: README, Lua sources, add-on manifest, available tests/assets. Actual runtime integration remains unverified here.
